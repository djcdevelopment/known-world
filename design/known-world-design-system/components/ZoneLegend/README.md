# ZoneLegend

The side panel that explains the selected zone: its name in `accent`, then *why*, *where* and *motion* as a definition list.

- Use `.kw-legend`, 300px wide (`legend-width`) beside the stage. It stacks under the stage below `board-break`.
- With nothing selected, it shows the layout name and the moment, plus one line of help.
- Terms use `kw-label`; definitions use `kw-small`.
